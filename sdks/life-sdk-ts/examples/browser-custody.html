Browser custody — D-Sub-C demo

This demo exercises the WebCryptoAnima + PasskeyOracle + RemoteAnimaClient flow from @broomva/life-sdk. Steps:

  1. Enroll a passkey (one-time, fires OS auth UI).
  2. Mint a Tier-User capability JWT (passkey signs challenge).
  3. Sign a fake EIP-712 transferWithAuthorization (delegates to server-side wallet).
  4. POST the signature to a fake haima endpoint.

Configuration

Set the lifegw base URL in the form below. For local dev against a mock server, leave the default http://localhost:8787. The lifegw /anima/custody/* routes ship in Stream R (parallel to this PR) — without a real backend, the buttons below will fail at the network step.
