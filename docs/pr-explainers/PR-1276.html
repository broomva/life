Why this exists

Standard speculative decoding pairs a big "target" model with a small "drafter" that guesses several tokens ahead; the target verifies them in one pass, so output is bit-for-bit identical — just faster. The catch: a generic small model makes a poor drafter. We measured it on an M4 Pro:

What makes the MTP drafter special (and hard to port)

It is not a normal transformer. Three architectural twists let an 80M model draft usefully — and each one is why mlx-lm needed a dedicated class rather than reusing gemma4_text:

The centroid logit head — ② that makes 80M affordable

A full softmax over Gemma's 262,144-token vocabulary on every draft step would dominate an 80M model's cost. Instead the drafter clusters the vocab into 2048 centroids of 128 tokens, scores the centroids, takes the top 32, and only computes real logits for those ~4096 tokens — roughly 64× cheaper.

centroid_logits = centroids(h)                    # (B, L, 2048)
top = argpartition(-centroid_logits)[:32]         # 32 best clusters
selected = token_ordering[top]                    # ~4096 candidate tokens
logits = scatter(min-1, selected, h · emb[selected].T)   # functional put_along_axis

The review story — why it's 9/10, not 6/10

Two independent reviewers (a devil's-advocate brief and the pr-review-toolkit code-reviewer) ran in parallel and converged on the same blockers — a strong signal. First pass: 6/10. None were happy-path math errors; all four were robustness traps that only bite in production:

#TrapFix
1Real-weight load failed — the one full-attention layer uses global_head_dim=512, not 256 Per-layer-type head-dim dispatch (mirrors gemma4_text)
2token_ordering sat in parameters(); a tree_map dtype-cast would silently corrupt the int32 gather buffer into floats Rename _token_ordering (underscore excludes it); install via sanitize side-channel
3make_cache returned [] → silently no-ops in zip(layers, cache) → attention without context Raise NotImplementedError with guidance
4Two .item() calls forced a GPU→host sync per draft token — defeating the drafter's whole purpose Build the values on-device; pass RoPE offset as mx.array

After fixes, round 2: 9/10, passed. Details in the as-built spec §10.
